# Provenance

Initial extraction: 2026-11-03, from the owner's PhysLM project.

- `tcp_overlay.py` and `tcp_overlay_adapter.py`: extracted common visual layer.
  Source snapshot SHA-256 hashes are recorded in `source_hashes.json`.
- `harness.py`: new, intentionally simplified single-episode orchestration.
  It is not a copy of the production batch runtime.
- LIBERO example: completed batch
  `kimi_k3_libero40_twoimage_demo_ablation_pass5_20261102`,
  `demo/task-00-repeat-01`, observation `ep125-node0-frame0`.
- RoboCasa example: completed batch
  `kimi_k3_robocasa111_mobile_v3_20261030`,
  `task-00-repeat-01`, observation `ep20000-node0-frame0`.
- Expected projection fixtures were generated by the original independent
  `tcp_axes_v2.py` implementations. Both camera views are tested; example RGB
  files are wrist-only. No object-ground-truth labels are supplied to the overlay.

The source code's existing all-rights-reserved notice is retained in LICENSE;
this repository does not introduce an open-source license. Benchmark imagery
is retained here as small private experiment examples; upstream benchmark asset
rights are not changed. No full dataset is redistributed here.

The bundled LIBERO simulator entry point (`rollout_libero_minimal.py`) and
`eta0_sim/` carry the camera capture, calibrated geometry, synchronized gripper,
validated absolute OSC trajectories and action prompt used by the project's
2026-11-19 frozen LIBERO evaluation. These are drawn from the evaluation adapter
and the owner's PhysLM rollout code. Only the simulator path is packaged.
The launcher fetches LIBERO at revision `8f1084e3132a39270c3a13ebe37270a43ece2a01`;
benchmark assets and model weights are supplied separately.
